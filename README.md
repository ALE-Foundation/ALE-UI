# ALE UI (v2 - WIP)

ALE UI is a UI library for HaxeFlixel, designed to be easy to use, quick to learn, and flexible to configure

In this branch, `hscript`, the project will be built almost entirely as a modpack for [ALE Psych](https://github.com/ALE-Psych-Crew/ALE-Psych), and once the library is sufficiently complete, it will be ported to Haxe and published on [Haxelib](https://lib.haxe.org/)
